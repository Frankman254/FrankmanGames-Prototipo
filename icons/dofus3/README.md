# Referencias visuales de Dofus 3

Por decisión del creador del 2026-11-06, las referencias extraídas se guardan
localmente en `reference_assets/dofus3/`, una ruta cubierta por `.gitignore`.
No se cargan, empaquetan ni distribuyen con el juego.

La extracción se realizó con UnityPy 1.25.4 y la versión de respaldo
`6000.3.16f1`. Resultado local: 90 060 PNG, aproximadamente 1,59 GiB, repartidos
entre Items, Monsters, Spells, UI y Worldmaps. Las variantes 1×, 2× y `all` se
conservan como familias distintas cuando existen.

Los assets publicables se crean desde cero y viven en `assets/`. Su contrato se
documenta en `docs/GUIA_INTEGRACION_ARTE_AUDIO.md` y su autoría/licencia en
`PROCEDENCIA.md`.
