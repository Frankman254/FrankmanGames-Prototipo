# Experimento de audio de mazmorra

`dungeon1.ogg`, `dungeon2.ogg` y `dungeon3.ogg` fueron aportadas por el creador
y corresponden a otro juego. No son música original de FrankmanGames y su autor
y licencia no están identificados.

Se conservan únicamente como experimento de desarrollo para probar la rotación
musical de mazmorras. No deben publicarse ni distribuirse en una versión del
juego hasta reemplazarlas por música propia o acreditar una licencia compatible.
